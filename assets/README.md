# Assets
This document establishes the purpose of this folder, standards and how to organize the files inside.

## Purpose
This folder is responsible for holding all media assets used in the project and their corresponding licenses.

## Organization
The assets must be grouped together based on their original asset pack, where assets are distributed on an individual basis they may be grouped with other assets from the same source which shares the same type of license.<br>

## Naming Convention
The assets, licenses and their folder/s must maintain their original filename in order to make each file traceable and comparable from their original source.<br>

Where assets are distributed on an individual basis, their folder maybe named using the format `{CREATOR_NAME}_{LICENSE}` in snake_case form.

# Assets
This document establishes the purpose of this folder, standards and how to organize the files inside.

## Purpose
This folder is responsible for holding all media assets used in the project and their corresponding licenses.

## Organization
The assets must be grouped together based on their original asset pack.<br>

Where assets are distributed on an individual basis they may be grouped with other assets from the same source which shares the same type of license.<br>

## Files Included
Each folder must contain a license file regardless of their license type.<br>

Where a license file is not provided, a screenshot showing the license declared by the creator through their distribution channels or through direct messaging with the explicit permission to share their message may suffice.

## Naming Convention
The assets, licenses and their folder/s must maintain their original filename in order to make each file traceable and comparable from their original source.<br>

Where assets are distributed on an individual basis, their folder may be named using the format `{CREATOR_NAME}_{LICENSE_TYPE}` in snake_case form where `{CREATOR_NAME}` is the licensor and `{LICENSE_TYPE}` is whether it's a cc0, mit or it can be declared as `custom` where the licensor have made their own version of a license.

Where screenshot is provided as proof of license in place of a text file as discussed in `Files Included` section, it may named `LICENSE.{EXT}` where `{EXT}` may come in form of png, jpg or any other standard media.

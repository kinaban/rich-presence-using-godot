# Theme
Themes are used for combining interconnected design and the ability to change the overall design by using a different theme.

The sections below discusses the best practices for creating, extending and organizing themes and its resources.

## Organizing
Each unique theme must have their own folder where its corresponding theme resource and other dependencies are located. In addition to this, the default theme must always be called `default`.

Inside each theme folder can be found the theme resource itself, and subfolders organized based on project needs.

All other themes must follow the same folder structure of the default theme.
